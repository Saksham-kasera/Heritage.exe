## 📖 The Problem & Vision

Over **80 million** domestic and international tourists visit India’s cultural treasures every year. Yet, travelers face three chronic, unresolved challenges:

1. **Dangerous Overtourism & Stone Erosion:** Flagship monuments (e.g., the Taj Mahal, Qutub Minar, Hawa Mahal) experience crippling 45+ minute bottlenecks and physical degradation, while equally magnificent sister heritage sites just 1–3 km away remain empty.
2. **Dense Signage & Language Fatigue:** Monolithic stone plaques are verbose, academic, and dry, failing domestic regional speakers, elderly pilgrims, and young children.
3. **Transit Scams & Insecurity:** Unregulated transit touts charge 300%–500% markups outside monument gates, while tourists lack instant emergency coordinates or fair tariff benchmarks.

**Safar Saarthi (सफ़र सारथी)** solves this at zero runtime cost. It is an edge-native, zero-build web companion that democratizes historical lore through **browser-synthesized bilingual voice narration**, mitigates crowd pressure through a **predictive dispersal engine**, and safeguards visitors with an **RTO fair-fare tariff calculator** and 1-tap emergency dispatchers.

## 🎨 Warm Editorial Design Language

Rooted in the timeless grace of travel broadsheets, botanical journals, and modern Scandinavian minimalism (analyzed in [`DESIGN-oura.md`](DESIGN-oura.md)):

* **Tactile Archival Canvas (`#f7f1e8`):** Fine cream paper backdrop that soothes eyes during bright daylight outdoor touring.
* **Hairline Broadsheet Structure (`#e1dcd3`):** 1px boundaries providing crisp structural definition without visual clutter.
* **Dual-Voice Typography:**
  * **The Editorial Voice (`Newsreader`):** High-contrast literary serif for historical chapters and monument titles.
  * **The Rationalist Voice (`Work Sans`):** Clean, high-legibility grotesque sans for telemetry, transit matrices, and controls.
* **Disciplined Chromatic Blue (`#2a72de`):** Reserved exclusively for decisive conversion actions (e.g., 1-Tap Google Maps Directions, Emergency Calling).


### 1. 🌤️ Mausam-X Precinct Weather Radar & Tour Planner
* **Precinct Microclimate Node:** Real-time temperature, heat index stress advisory, relative humidity, UV exposure levels, and surface wind vectors.
* **Hourly Rain & Thermal Comfort Window:** 6-interval bar chart projecting comfortable touring windows.
* **Optimal Visiting Window Banner:** Highlights the calmest 2.5-hour morning window with lowest wait times.
* **AI Multi-Day Tour Planner:** Generates 1 to 5-day itineraries tailored to *Contemplative* (max 2 sites/day) or *Comprehensive* pacing.

### 2. 🎧 Bilingual Audio Chronicles & Lore Engine
* **Browser-Native Web Speech API:** Zero paid API keys, zero cloud latency. Speaks natural Indian English (`en-IN`) or Hindi (`hi-IN`).
* **Dual Voice Narrator:** Toggle between 👩 **Sunita** (*Warm, Conversational*) and 👨 **Vikram** (*Deep Baritone*).
* **Live Equalizer Visualizer:** 6 dynamic soundwave bars that animate rhythmically during narration.
* **✨ Kids' Mode Toggle:** One-tap transformation that translates dense historical dates into engaging fairy tales, magical metaphors, and playful myths with an elevated speech pitch (1.15x).
* **💡 Tap-to-Reveal Secret Fact:** Interactive 180° flip drawer revealing anti-seismic engineering, acoustic marvels, and hidden tunnels.

### 3. 🌿 Dynamic Footfall Dispersal Engine & ⚡ Surge Mode
* **11-Hour Footfall Histogram (8 AM – 6 PM):** Color-coded by capacity:
  * 🟢 **Low (<45%):** Calm walking conditions.
  * 🟡 **Moderate (45–84%):** Anticipate 10–20 min wait.
  * 🔴 **Peak (85%+):** Severe bottleneck alert.
* **Dynamic Sister Gem Diversion:** When a monument exceeds 80% capacity, the system triggers the **Quieter Alternative Nearby** card (e.g., Mehtab Bagh across the Yamuna with 18% crowd and 0 min wait) paired with a 1-tap Google Maps Universal Intent link.
* **⚡ Live Demo Surge Mode:** A discrete trigger for presentations that instantly simulates 95% peak footfall so judges can watch the dispersal engine activate in real time.

### 4. 🛡️ Transit Shield & Scam Sentinel
* **Interactive Fair-Fare Calculator:** Drag the distance slider (1–25 km) with Night Surcharge (+25%) to inspect RTO-regulated tariffs (Base ₹30 for 1.5 km + ₹11/km) across:
  * 🛵 **Rapido Bike:** Solitary agile transit.
  * 🛺 **Auto-Rickshaw:** Meter benchmark with anti-tout scam warnings.
  * 🚗 **Uber / App Cab:** AC hatchback.
  * 🚘 **Prime Sedan:** Extra luggage & family comfort.
* **1-Tap Direct SOS:** Native OS protocol dialers for `tel:112` (National Emergency) and `tel:1363` (Ministry of Tourism 24x7 Multi-lingual Helpline).
* **Localized Support:** Automatically displays the exact Tourist Police booth and emergency trauma hospital for the currently viewed site.

### 5. 📝 Visitor Feedback & Safety Ledger
* **Tactile 5-Star Experience Rating:** Instant rating with dynamic satisfaction labels (*Needs Review* to *Delightful*).
* **Telemetry Validation:** Micro-audits for Mausam-X prediction accuracy and local audio pronunciation.
* **Confidential Tout Incident Reporter:** Narrative box with auto registration plate tracking and an immediate Tourist Police dispatch flag.
* **Cryptographic Ledger Receipt:** Submissions generate an immutable receipt hash (e.g., `#ASI-AGRA-8839`) logged to an anonymous safety ledger.

## 🏗️ Zero-Cost Edge Architecture

Designed to run smoothly on any mobile browser, school laptop, or static CDN without incurring infrastructure bills:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        SAFAR SAARTHI TECH STACK                        │
├─────────────────────┬──────────────────────────────────────────────────┤
│ Markup & Structure  │ Semantic HTML5 (Single-Page App Layout)          │
│ Styling & Theming   │ Tailwind CSS CDN + Warm Editorial Custom CSS     │
│ Typography & Icons  │ Google Fonts (Newsreader, Work Sans) + Material  │
│ Logic Engine        │ Modern Vanilla JavaScript (ES6+), Zero Bundlers  │
│ Voice Synthesis     │ window.speechSynthesis (en-IN / hi-IN Voices)   │
│ Mapping & Routing   │ Google Maps Universal Intent Protocol URLs       │
│ Microclimate Radar  │ Open-Meteo REST API with Pre-calibrated Offline  │
│ Telemetry Dataset   │ Structured JSON (data.js) with zero-fetch fallback│
└─────────────────────┴──────────────────────────────────────────────────┘
```

### 🔒 Architectural Guardrails:
* ❌ **No Build Tools:** No Vite, Webpack, Babel, or Next.js overhead.
* ❌ **No Backend Runtime:** No Node.js or Python backend server required for visitors.
* ❌ **No Paid API Keys:** No Google Maps JS SDK billing keys or cloud TTS tokens.
* 🛡️ **Offline & `file:///` Resilient:** Runs directly by double-clicking `index.html` without local server CORS errors.

## 🚀 Quick Start & Live Preview

### Option 1: Instant Local Preview (Zero Install)
Simply double-click `index.html` in your file explorer, or launch with any static server:

```bash
# Clone the repository
git clone https://github.com/Saksham-kasera/Heritage.exe.git
cd Heritage.exe

# Start lightweight preview server (Node.js built-in)
node server.js
```
Open **[http://localhost:3000/](http://localhost:3000/)** in your browser.

### Option 2: All-in-One Standalone File
Open [`safarsaarthi-standalone.html`](safarsaarthi-standalone.html) directly in any web browser. All HTML, CSS, JavaScript, and datasets are bundled into a single file for zero-latency distribution.
